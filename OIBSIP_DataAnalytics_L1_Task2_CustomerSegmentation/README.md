Dataset

The dataset used in this project is the Online Retail Dataset from Kaggle/UCI.

Dataset Link:
https://www.kaggle.com/datasets/vijayuv/onlineretail

Since the dataset exceeds GitHub's web upload limit, it has not been included in this repository.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Features
- Data Cleaning
- RFM Feature Engineering
- Data Standardization
- Elbow Method for Optimal K
- K-Means Clustering
- Cluster Visualisation
- Customer Segment Profiling
- Marketing Recommendations

## Results
The customers were segmented into four distinct groups based on their purchasing behaviour, enabling targeted marketing strategies.
